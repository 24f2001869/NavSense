# Archive Directory Guide

This directory stores historical, superseded, and exploratory code and artifacts that are no longer part of the active production navigation pipeline, but are preserved to maintain a complete research record.

---

## 1. Directory Structure

* **`archive/superseded/`**: Earlier iterations of algorithms and diagnostic scripts that have been replaced by more mature implementations (e.g. initial Stage C5 single-trip models, exploratory plotting scripts).
* **`archive/obsolete/`**: Formats, experimental configs, and testbeds that are no longer compatible with the current architecture.
* **`archive/exploratory/`**: Experimental proof-of-concept scripts that did not lead to an accepted feature.

---

## 2. Policy on Archival
In accordance with open research principles, **no failed experiments are deleted**. Code is archived with documentation explaining why it was superseded, ensuring that future researchers can inspect the evolutionary history of the system.
