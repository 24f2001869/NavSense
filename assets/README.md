# Assets & Visualizations Guide

This directory stores curated figures, system architecture diagrams, and diagnostic dashboards displayed across repository documentation and GitHub previews.

---

## Directory Organization

* **`assets/architecture/`**: System diagrams, filter flowcharts, and pipeline schematics.
* **`assets/experiments/`**: Authoritative multi-panel benchmark dashboards:
  - `adaptive_fusion_plots.png`: Phase 5.6 multi-horizon benchmark dashboard.
  - `stateful_kinematics_plots.png`: Phase 5.5 momentum vs kinematics comparison.
  - `highway_observability_plots.png`: Phase 5.4 steady-state cruise distribution and ROC curves.
  - `vibration_spectrum_plots.png`: Phase 5.3 spectrograms and frequency vs speed scatter plots.
  - `expanded_tcn_benchmark_summary.png`: Phase 5.1/5.2 19-trip drift waterfall.
  - `balanced_tcn_benchmark_summary.png`: Phase 5.2 Pareto trade-off summary.
  - `c8_4_closed_loop_map_matching.png`: Stage C8-4 closed-loop map matching diagnostics.
* **`assets/screenshots/`**: Screenshots of the mobile navigation UI (`phone_screenshot.png`).
