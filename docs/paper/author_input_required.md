# Author Input Required for Manuscript Submission

This document lists strictly the metadata and administrative information that cannot be determined from the repository or public literature, which the primary author must provide prior to final manuscript submission.

---

## Required Author Information

| Field Identifier | Required Item | Description | Default Placeholder in Manuscript | Action Required from Author |
|:---:|:---|:---|:---|:---|
| **AUTH-01** | **Author Full Name(s)** | Full legal / publication name(s) of the author(s). | `[Author Name(s) — AUTHOR INPUT REQUIRED]` | Provide author name(s) in order of contribution. |
| **AUTH-02** | **Institutional Affiliation(s)** | Department, University / Institution, City, Country. | `[Department of ..., University / Institution, City, Country — AUTHOR INPUT REQUIRED]` | Provide official institutional affiliation. |
| **AUTH-03** | **Corresponding Email** | Academic or institutional email address for correspondence. | `[author@institution.edu — AUTHOR INPUT REQUIRED]` | Provide contact email. |
| **AUTH-04** | **Target Publication Venue** | Preferred conference, workshop, or journal for initial submission. | `[Target Venue: e.g., IEEE PLANS 2027 / IEEE IV 2027 / ION GNSS+ — AUTHOR INPUT REQUIRED]` | Select target venue to adjust formatting/page limits. |
| **AUTH-05** | **Funding & Grant Acknowledgments** | Any financial grants, university research sponsorships, or hackathon institutional support. | `[Funding statement / No specific external grant received — AUTHOR INPUT REQUIRED]` | Specify grant numbers or write "None". |
| **AUTH-06** | **Competing Interest Statement** | Declaration of financial or commercial conflicts of interest. | `The authors declare that they have no competing financial or non-financial interests.` | Confirm statement or provide details. |
| **AUTH-07** | **Physical Test Vehicle (Future Roadmap)** | Vehicle model and RTK hardware to be used for the upcoming physical road validation drive. | `[Planned Validation: Vehicle Make/Model, Dual-Frequency RTK Reference — AUTHOR INPUT REQUIRED]` | Optional: Specify vehicle if planned soon. |
